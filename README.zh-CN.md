# drawgui

[English](README.md)

drawgui 是一个用 C++20 写的轻量自绘 GUI 框架。所有界面都由它自己用 Skia 在 CPU 上绘制，窗口通过 SDL3 创建；同时导出一套纯 C 接口，任何能调用 C 函数的语言都可以使用。

有两种用法：

- **C++**：使用 `dg::App` / `dg::Window` 运行时。创建节点、设置属性、读取事件即可，布局、绘制、输入、焦点、弹层和动画都由运行时处理。
- **C**：使用 C 接口（`include/drawgui/abi/drawgui.h`），它是同一个运行时外面的一层薄封装。

## 特别之处

- **任何语言都能嵌入。** 整个框架都可以通过纯 C 接口使用。宿主语言不需要 Dart 虚拟机、QML 引擎或内嵌浏览器，只要能调用 C 函数就行。C 接口由一份定义文件（`abi/drawgui.def.toml`）生成并加锁，不小心改坏兼容性时构建会直接失败。
- **一个运行时，两种入口。** C 接口只是 C++ `dg::App` 运行时外面的一层薄封装，不是另一套实现，C 和 C++ 程序的行为完全一致。
- **只做变化的那部分工作。** 每帧最多布局一次，而且只处理有变化的节点；滚动、输入文字、拖动滑块、列表复用行、焦点切换、切换主题都不会触发重新布局。重绘也只限于变化的区域。
- **空闲时不占 CPU。** 没有动画时事件循环直接阻塞等待，只有动画进行时才按帧唤醒。
- **大数据量，固定开销。** 列表、树、表格只复用一小组行节点，1 万行和 20 行的开销差不多。
- **依赖少。** 用 Skia 在 CPU 上绘制，不需要 GPU，也不链接 libGL。中日韩文字、双向文字和复杂文字的排版不需要 ICU 数据文件。
- **能力内置在组件里。** 键盘操作、对话框焦点限制、快捷键、提示、禁用状态、主题、关闭确认都是组件自带的，应用不用自己写胶水代码。
- **Skia 的绘制质量。** 所有界面都由 Skia 绘制，它也是 Chrome 和 Flutter 使用的 2D 引擎：抗锯齿的图形和圆角、平滑的渐变、柔和的阴影、整组透明度、矢量 SVG 和高质量文字，在每台机器上效果一致。底层 C++ 代码仍然可以直接使用 Skia 画布（见 `examples/02_skia_cpu_gallery`）；运行时里暂时还没有自定义绘制节点。
- **Flexbox 布局。** 布局模型接近 CSS Flexbox：行和列方向、多行换行、`justify`（start/end/center、space-between/around/evenly）、`align` 和 `align_self`、换行后的 `align_content`、`gap` 和 `run_gap`、`grow`/`shrink`/`basis`、最小/最大尺寸、`aspect_ratio`、百分比和 `auto` 尺寸，以及用 `left`/`top`/`right`/`bottom` 绝对定位。窗口改变大小时，只重新计算受新尺寸影响的部分。
- **类 CSS 的样式属性。** 71 个属性，名字和含义都接近 CSS：外边距和内边距、边框和圆角、线性和径向渐变、阴影、整组透明度，以及 `overflow` 裁剪（同时裁剪点击区域）。每个属性都有数字 id，普通数值类属性在任何语言里都通过同一个函数 `dg_node_set_prop()` 设置（渐变和阴影目前只能在 C++ 里设置）。
- **开箱即用的中文和 emoji。** 只写一个字体名，就能通过自动字体回退覆盖中文、日文、韩文等 12 种文字和彩色 emoji。用语言标签可以选择对应的汉字字形（简体、繁体、日文）。中文不需要空格也能正确换行；编辑时按完整字符移动，emoji 和组合字符不会被拆开。
- **SVG 图标按矢量绘制。** SVG 按矢量绘制，任何尺寸都清晰；还可以用主题颜色着色，跟随亮暗主题切换。同时支持 PNG、JPEG、WebP，有 fill/contain/cover/none 四种缩放方式。
- **有测试兜底。** 每个示例都有自检模式，渲染结果与基准图逐像素比对，整套测试还会在 AddressSanitizer 下运行。

## 组件

| 组件 | 说明 |
| --- | --- |
| Box | 容器，子节点可按行、列、换行或绝对定位排列 |
| Label | 文字，单行或自动换行，支持省略号 |
| Image | PNG/JPEG/WebP/SVG 图片，支持缩放方式和跟随主题的着色 |
| Button | 按钮；设置 `checked` 后成为切换按钮；图标和文字自动居中 |
| Checkbox | 带文字的复选框 |
| Radio | 单选按钮，按分组 id 互斥 |
| Slider | 水平滑块，支持鼠标和键盘 |
| TextField | 单行编辑框：选择、剪贴板、撤销重做、占位文字、长度限制、输入法 |
| TextArea | 多行编辑框，自动换行，按可见行移动光标 |
| ScrollView | 带滚动条的滚动区域，支持滚轮和拖动 |
| List | 虚拟列表；行可以带图标、辅助文字、复选框和操作按钮 |
| Tree | 虚拟可展开树，支持同样的富内容行 |
| Table | 虚拟表格，可按列排序，支持富内容行 |
| Dropdown | 下拉选择框，也能在对话框里使用 |
| ProgressBar | 进度条，确定或不确定进度 |
| Tabs | 标签页，支持禁用某个标签 |
| MenuBar | 应用菜单栏，显示快捷键，支持 F10/Alt 键盘操作 |
| Menu | 右键或弹出菜单，可用鼠标、菜单键或 Shift+F10 打开 |
| Tooltip | 任意节点的悬停提示 |
| Dialog | 模态对话框，带按钮，可放表单，焦点限制在对话框内 |

所有节点都支持通用属性：尺寸、外边距、内边距、颜色、边框、圆角、渐变、阴影、透明度、`visible`、`disabled`、鼠标指针样式和节点用户数据（共 71 个属性）。

## 其他功能

- **文本**：中日韩文字、emoji、双向文字和复杂文字，自动换行、选择、剪贴板、撤销重做和输入法。
- **输入**：焦点和 Tab 顺序、应用自定义快捷键（全局或区域内）、键盘打开右键菜单、双击和三击。
- **动画**：显式动画和隐式过渡，支持缓动曲线、完成事件和"减少动画"设置。
- **主题**：20 个设计变量，亮色和暗色，以及可在运行时重新加载的外部主题包。
- **窗口**：一个应用可有多个窗口，支持标题、尺寸、位置、最小化/最大化、全屏、图标和关闭确认。
- **C 接口**（0.2 版）：116 个函数、17 种节点、71 个属性、32 种事件。事件采用轮询方式，没有回调。

## 进展

- 目前只支持 **Linux**，窗口后端是 SDL3。
- 只用 CPU 绘制，不需要 GPU。
- 运行时、控件和上面列出的桌面应用能力都已完成，并有测试覆盖：43 项 CTest、865 个单元测试用例、8 张基准图，全部通过。
- C 接口为 0.2 版，尚未正式发布，还可能变化。
- 尚未完成：Windows、macOS 和移动端，无障碍，子菜单，多选，单元格编辑，自定义绘制节点，以及其他语言绑定（下一步计划做 JavaScript）。

完整的已知限制见 `doc/limitations.md`。

## 构建

```sh
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build
ctest --test-dir build --output-on-failure
./build/examples/drawgui_showcase
```

第一次配置时会下载预编译的 Skia 和 doctest。环境要求和第一个程序见 `doc/getting-started.md`，各类指南和参考见 `doc/` 目录。
