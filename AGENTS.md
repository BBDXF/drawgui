## Repository Map

A full codemap is available at `.slim/codemap/codemap.md` (local only, git-ignored).

Before working on any task, read `.slim/codemap/codemap.md` to understand:
- Project architecture and entry points
- Directory responsibilities and design patterns
- Data flow and integration points between modules

For deep work on a specific folder, read the mirrored map at `.slim/codemap/<folder>/codemap.md`
(e.g. `src/render/` -> `.slim/codemap/src/render/codemap.md`).

If the maps are missing or stale, regenerate with the `codemap` skill.
